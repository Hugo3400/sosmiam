# Arborescence de SOS Miam

```
sos-miam/
├── CLAUDE.md                  règles du projet
├── .claude/workflows/         workflows réutilisables des sessions Claude : verifier-avant-redemarrage.js (avant un redémarrage de l'API, trois vérificateurs en lecture seule : tests et démarrage d'essai, migrations face à la base, ce qui part en ligne ; rend « stable » ou la liste de ce qui reste à régler)
├── docs/                      arborescence (ce fichier), décisions produit, idées pour plus tard (idees.md) et procédure de changement de la clé des données des comptes (procedure-changement-cle.md)
├── presse/                    Espace presse du logiciel de gestion : affiches (A4, A3, 40 × 60 cm), réseaux, campagne ambassadeurs fondateurs, imprimés, Capitaine, flyer, Miam Safe, documents, visuels stores, kit de marque, images, vidéos et sons (PNG, JPG, SVG, PDF, Markdown, MP4, sons), avec index.json, aperçus et un zip par famille ; kits/ : les zips que servent aussi les kits médias du site (contenus/maquettes-kits.ts) ; videos/ hors git (voir LISEZMOI.md)
├── kits/                      kit de marque (logos, mascotte Capitaine Bouiboui, pictos, bannières, couleurs, avatars des Miamis ; voir LISEZMOI.txt) et archives des vidéos
├── scripts/                   outils du dépôt (verifier-lignes.sh, deployer-site.sh, generer-kit-media.sh, generer-kit-media-pro.sh, generer-kit-media-lieux.sh, recuperer-inscrits.py, lire-boite-mail.py, autoriser-poste-gestion.ts, regler-boite-mail.ts, preparer-communes.ts…) ; presse/ : exporter-maquettes.py et assembler-presse.py, qui refont presse/ depuis les canevas (voir scripts/presse/LISEZMOI.md) ; avatars-miamis/ : les dessins des Miamis (bouée, visages, couvre-chefs) et generer-avatars-miamis.ts, qui refait kits/SOS_Miam_kit_de_marque/06_Avatars_des_Miamis
├── apps/
│   ├── site-web/              LE SITE (React Router 8)
│   ├── app-mobile/            L'APP iOS + Android (Expo)
│   ├── logiciel-gestion/      LE LOGICIEL ORDINATEUR de gestion (Tauri), réservé aux postes autorisés de Hugo
│   ├── api/                   LE SERVEUR (Express + Prisma + PostgreSQL)
│   └── bot-discord/           LE BOT du serveur Discord (discord.js)
└── packages/
    └── commun/                code partagé par le site, l'app et l'API
```

## apps/site-web — le site
| Dossier | Contenu |
|---|---|

| `src/validation/` | règles des formulaires (inscription, demande de BIG SOS…, défi écrit dans le logiciel de gestion : `valider-defi.ts`) ; partie sociale : textes (`verifier-texte-social.ts` ; fins de ligne `\r\n`, `\r`, `\v`, `\f`, NEL, U+2028 et U+2029 changées en `\n` avant de vérifier et de garder : `nettoyer-texte-social.ts` ; rien d'invisible ni de caractère de contrôle : `est-texte-affichable.ts`), nouvelle sortie, liste ou groupe, signalement d'un contenu social (précision et explication nettoyées, contrôles retirés, tabulation gardée : `nettoyer-texte-signalement.ts`, que l'app utilise aussi pour compter les 10 caractères de « autre »), emoji seul, idClient ; avatar d'une photo de profil (`lire-avatar-photo.ts`) |
| `src/client-api/` | contrats des services (visites, fidélité, réservations, avis, comptoir, lieu côté équipe (SOS du soir, message du moment, statistiques, événements : `contrat-lieu-pro.ts`), espace ambassadeur, « Ça m'intéresse » sur les événements (`contrat-interets-evenements.ts`), inscription du téléphone aux notifications (`contrat-appareils.ts`), Miam Safe, suggestions, activité, contenu, compte, défis (`contrat-defis.ts`)) et forme des réponses de l'API ; `client-http.ts` : le client HTTP de l'API (session en Bearer, erreurs traduites en ErreurService ; il envoie aussi un corps en octets, photo ou note vocale, et prépare le téléchargement d'un fichier privé, jeton dans l'en-tête, jamais dans l'adresse) ; partie sociale : bande et blocages (`contrat-bande.ts`), suivis entre personnes (`contrat-suivis-personnes.ts`), sorties (`contrat-sorties.ts`), listes de lieux (`contrat-listes.ts`), commentaires des publications (`contrat-commentaires.ts`), signalements sociaux (`contrat-signalements-sociaux.ts`), décisions de la modération (`contrat-moderation-app.ts`), messagerie et lieux envoyés (`contrat-messagerie.ts`) |
| `src/client-api/api/` | la version API de chaque service (un fichier par service : `api-visites.ts`, `api-comptoir.ts`, `api-compte.ts`…), l'écoute régulière des écrans abonnés, et l'assemblage `creer-services-api.ts` ; partie sociale : `api-bande.ts`, `api-suivis-personnes.ts`, `api-messagerie.ts`, `api-sorties.ts`, `api-listes.ts`, `api-commentaires.ts`, `api-signalements-sociaux.ts`, `api-moderation-app.ts` (assemblés par `creer-services-sociaux-api.ts`) |
| `tests/` | tests des règles (`npm run commun:tester`) |
