# Arborescence de SOS Miam

```
sos-miam/
├── CLAUDE.md                  règles du projet
├── .claude/workflows/         workflows réutilisables des sessions Claude : verifier-avant-redemarrage.js (avant un redémarrage de l'API, trois vérificateurs en lecture seule : tests et démarrage d'essai, migrations face à la base, ce qui part en ligne ; rend « stable » ou la liste de ce qui reste à régler)
├── docs/                      arborescence (ce fichier), décisions produit, idées pour plus tard (idees.md), procédure de changement de la clé des données des comptes (procedure-changement-cle.md), plan de la version anglaise (version-anglaise.md) et son glossaire (glossaire-anglais.md)
├── presse/                    Espace presse du logiciel de gestion : affiches (A4, A3, 40 × 60 cm), réseaux, campagne ambassadeurs fondateurs, imprimés, Capitaine, flyer, Miam Safe, documents, visuels stores, kit de marque, images, vidéos et sons (PNG, JPG, SVG, PDF, Markdown, MP4, sons), avec index.json, aperçus et un zip par famille ; kits/ : les zips que servent aussi les kits médias du site (contenus/maquettes-kits.ts) ; videos/ hors git (voir LISEZMOI.md)
├── kits/                      kit de marque (logos, mascotte Capitaine Bouiboui, pictos, bannières, couleurs, avatars des Miamis, tenues de saison du Capitaine ; voir LISEZMOI.txt) et archives des vidéos
├── scripts/                   outils du dépôt (verifier-lignes.sh, deployer-site.sh, generer-kit-media.sh, generer-kit-media-pro.sh, generer-kit-media-lieux.sh, recuperer-inscrits.py, lire-boite-mail.py, autoriser-poste-gestion.ts, regler-boite-mail.ts, preparer-communes.ts…) ; presse/ : exporter-maquettes.py et assembler-presse.py, qui refont presse/ depuis les canevas (voir scripts/presse/LISEZMOI.md) ; avatars-miamis/ : les dessins des Miamis (bouée, visages, couvre-chefs) et generer-avatars-miamis.ts, qui refait kits/SOS_Miam_kit_de_marque/06_Avatars_des_Miamis ; tenues-capitaine/ : les accessoires des tenues du Capitaine (thèmes de saison) et generer-tenues-capitaine.ts, qui refait kits/SOS_Miam_kit_de_marque/07_Tenues_du_Capitaine, les PNG de l'app et les SVG du site ; essai-ecrans-gestion/ : `npm run gestion:essai-ecrans` ouvre tous les écrans du logiciel de gestion dans Chromium (playwright-core, son propre package.json), face à une API d'essai qui répond en erreur à tout, et échoue si un écran plante ; lancé aussi avant chaque installateur (`SANS_ESSAI_ECRANS=1` pour passer outre)
├── apps/
│   ├── site-web/              LE SITE (React Router 8)
│   ├── app-mobile/            L'APP iOS + Android (Expo)
│   ├── logiciel-gestion/      LE LOGICIEL ORDINATEUR de gestion (Tauri), réservé aux postes autorisés de Hugo
│   ├── api/                   LE SERVEUR (Express + Prisma + PostgreSQL)
│   └── bot-discord/           LE BOT du serveur Discord (discord.js)
└── packages/
    └── commun/                code partagé par le site, l'app et l'API
```
